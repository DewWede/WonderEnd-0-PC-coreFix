# WonderEnd-0-PC-Optimization-Fix(coreFix)
Фикс-патч swf файла WonderEnd0, созданное компанией Lunime, который оптимизирует скрипты игры на пк. 

**Скачать файл можно на странице релизов:** https://github.com/DewWede/WonderEnd-0-PC-coreFix/releases
**Ссылка на официальную игру:** https://wonderend.com/

**Этот репозиторий не является коммерческим**, а также создан исключительно для личного исправления скриптов самой игры. Все права и авторство на игру принадлежат Lunime. Автор данного репозитория ни в коем случае не преследует цель забрать авторство над игрой себе.

**Инструкция на скачивание:**
1. Скачайте .swf файл со страницы релизов.
2. Распакуйте в удобное для себя место
3. Зайдите в директорию игры WonderEnd0 и замените .swf файл на скачанный.
